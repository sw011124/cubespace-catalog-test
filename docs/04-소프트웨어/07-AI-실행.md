# AI 실행 조정

이 문서로 답하는 것: AI 모드에서 놓인 큐브로 무엇을 실행 명세로 고정하고, 단계를 어떤 순서·권한으로 돌리며, 언제 멈추고 무엇을 보이나.

관련: [03 상태기계](03-상태기계.md) 17절 · [05 표시](05-표시.md) · [08 동반 앱](08-동반-앱.md) · [PC 내부 4 서비스 → AI CLI](../03-인터페이스/03-PC-내부.md)

CLI 인자·설정 파일·환경 변수 값과 금지 인자는 [PC 내부 4](../03-인터페이스/03-PC-내부.md)에 있다. 이 문서는 실행 규칙만 적는다.

## 1. 경계

- main 안 모듈, TypeScript. CLI 설치본을 그대로 부른다(Agent SDK·Codex SDK 안 씀).
- 맡지 않음: AI 후보·물리 사건(상태기계), IPC 검사(main), 패드 그리기(`ai_problem`만 냄).
- 화면 제어 경로에는 네트워크·AI 호출이 없다. AI를 못 써도 화면 제어·프로필 편집은 동작한다(REQ-056).

## 2. 프로필과 명세 고정

| 프로필 | 칸·규칙(REQ-009) |
|---|---|
| 에이전트 | 공급자(Claude Code / Codex), 모델 전체 이름, 역할 `plan_review` / `implement_fix`. 바꾸면 새 판 = 새 세션 |
| 프로젝트 | 로컬 절대 경로 작업 폴더, 목표, 지침 파일, 테스트(`argv`·`timeout_s`·`protected`·`report`·`min_count`), `session_policy`(`resume` / `fresh`), `limits` |
| 프롬프트 / 스킬 | 본문 ≤ 32 KB, 변수 `{{이름}}` / `SKILL.md` + 참조 텍스트 합 64 KB, 스크립트 실행 없음 [권장안 U-82] |
| MCP / 묶음 | 로컬 stdio만(앱이 고정 판을 설치한 npm 패키지 포함), 도구별 R/W와 허용 도구 목록 [권장안 U-103] / 검증된 조합 |

- 프로필은 서비스만 쓴다. 저장마다 새 판 + 파일별 SHA-256. 실행 파일·폴더 등록은 OS 확인 창([08](08-동반-앱.md) 9절).
- 참여 큐브 = 시작 순간 AI 후보 ∩ 놓임(≤ 4). 에이전트 1~2 + 프로젝트 1 + 프롬프트.
- `spec.json`(`spec_ver` 1)에 고정: 참여 큐브(좌표 = 마지막 ON_PAD 중심)와 프로필 `profile_id`·`ver`·`sha256`, 목표, 단계 등급, MCP 허용 도구, 한도, 프롬프트 순서(REQ-040).
- `runs\<run_id>\`에 프롬프트·스킬·지침·MCP 설정·CLI 설정·출력 스키마·테스트 명령을 내용째 복사하고 단계는 이 폴더만 읽는다. 세션 ID는 DB에만 둬서 `spec_sha256`이 바뀌지 않는다.
- 미리보기가 `candidate_sha256`을 싣고 시작 요청이 되돌려 보낸다. 다르면 `stale_preview` 거절 + 새 미리보기.
- 물리 사건은 실행 입력이 아니다. 빠진 명세 큐브는 끝날 때까지 회색 점멸 [권장안 U-35].
- AI 프리셋(K8, REQ-061): 큐브별 프리셋 기본값은 모두 (없음)으로 시작한다(설정 항목은 남김). 추천 배정의 '적용'(REQ-062 ④⑤)은 없애고 `이 구성으로 모드 만들기`만 둔다(묶기 재설계).
- 프로필 후보는 AI 확장 목록(서버, [01 구성](01-구성.md) 2.1절)에서 오고, 프리셋은 용도 → 요구 카드 → 고르기·배치 → 확인 순서로 만든다. 목록 만들기와 프리셋 만들기 전체는 [설계 ai-preset-builder](../specs/ai-preset-builder.md)다. MCP는 도구마다 R/W가 있어 R 단계에는 R 도구만 연다(`--allowedTools`).

## 3. 구성 검증(REQ-039)

`ai_member`마다, 시작 직전에 다시. 오류면 시작 버튼을 끄고 큐브에 딸린 오류는 빨강 점멸.

| 코드 | 조건 |
|---|---|
| E01·E02·E03 | 에이전트 없음 / 3개 이상 / 2개 역할 같음 |
| E04·E05·E06 | 프로젝트 없음 / 2개 이상 / 요청 없음·채우지 않은 변수 |
| E07·E08·E09 | 프로필 없음 / 원본 해시 다름 / MCP 파일 없음·해시 다름·작업·임시 폴더 안 |
| E10·E11·E12 | CLI 없음·로그인 안 됨·판 ≠ 고정값 / 작업 폴더 문제(없음, 네트워크 경로, 20,000개·1 GB 초과) / 테스트 실행 파일 못 찾음·`.exe` 아님 |
| W01~W08 | 순서 애매, 테스트 없음, git 아님, AGENTS.md 있음, 목록 큐브가 패드 밖, 공급자 차이, 판정은 네트워크 없음, 테스트 보고 파일 없음 |

- 프롬프트 순서: x 작은 것부터(같으면 y, 그다음 cube_id). 앞 열 첫 큐브와 x 차이 < 17.5 mm면 같은 열, 열 안은 위부터. 애매 = 두 프롬프트 큐브의 x 차이 12.5 이상 22.5 mm 미만 ∧ x·y 순서가 반대.
- 애매할 때만 'AI 추천 받기' [권장안 U-63]: 도구 없는 1회 호출, 60 s, 저장 안 함. '적용'해야 반영. 실패면 규칙 순서.

## 4. 단계

A = 에이전트가 1개일 때 그 에이전트, P = 계획·검토 에이전트, I = 구현·수정 에이전트. 등급 R = 읽기만(`Read,Grep,Glob`), W = 작업 폴더 쓰기 허용([PC 내부](../03-인터페이스/03-PC-내부.md) 4절).

| 에이전트 | 단계(등급) | 수정 왕복 |
|---|---|---|
| 1개 A | 구현(A, W) → 판정 → [수정(A, W) → 판정] | 판정 실패 때 |
| 2개 P·I | 계획(P, R) → 구현(I, W) → 판정 → 검토(P, R) → [수정(I, W) → 판정 → 검토(P, R)] | 판정 실패 또는 `changes` |

- 기본 역할: Claude Code = 계획·검토, Codex = 구현·수정 [권장안 U-28]. Windows Claude는 파일 도구만 [권장안 U-54].
- 단계 출력은 strict JSON 스키마. 서비스가 문자열 4,000자·배열 20개로 자르고 `truncated`를 남긴다.
- 프롬프트는 stdin으로만. 조립: 머리 → 역할 → 규칙 → 목표 → 프롬프트 → 스킬 → 지침 → 앞 실행 요약 → 앞 단계 결과 → 판정 결과 → 변경 내용. 1 MB 넘으면 변경 → 판정 → 스킬 순으로 자른다.
- 실행 중 승인은 없다. 사람 확인은 단계 경계 대기 사유 5개에서만 [권장안 U-27].
- 판정(W 단계 끝마다): 기준점(경로·크기·SHA-256) 비교 → 보호 파일 변경·테스트 패턴(`**/test_*.py`, `**/*_test.*`, `**/*.test.*`, `**/*.spec.*`) 밖 새 파일·`node_modules/**`·`.venv/**`·`venv/**` 안 추가·수정·삭제면 `tests_changed` → 지침·설정 경로(`**/CLAUDE.md`, `**/CLAUDE.local.md`, `**/AGENTS.md`, `**/AGENTS.override.md`, `.claude/**`, `.mcp.json`, `.codex/**`, `.agents/**`, `.vscode/**`, 지정 지침 파일) 변경이면 `config_file_changed` → Codex 샌드박스에서 테스트(네트워크 끔, 키 없음, 300 s) → 통과 = 종료 코드 0 ∧ 보고 파일 새로 생김 ∧ 실행 수 ≥ `min_count` ∧ 실패 0 → 기준점 다시.
- 테스트 없는 프로젝트는 판정 없이 마지막 단계 뒤 `no_tests`. 격리 시험 미달이면 확인 창으로 허용한 프로젝트만 사용자 권한 테스트 [권장안 U-30].
- 격리(REQ-043): 작업 폴더의 훅·`.mcp.json`·설정·스킬·지침 파일을 적용하지 않는다. 전용 설정 폴더 `claude-home`·`codex-home`. 파일 범위는 작업 폴더 안. 명세 MCP·허용 도구만. 부모 환경을 물려주지 않는다. 키는 그 CLI 자식에만 [권장안 U-53]. 실행마다 `--version` 확인(E10). 판은 AI-T0(5주차)에 고정하고 Claude Code ≥ 2.1.259(`--permission-prompts`)다. 실제 로드(Claude `system/init`)가 명세와 다르면 `config_mismatch`, Codex가 허용 밖 도구를 쓰거나 R 단계에서 파일을 바꾸면 `sandbox_violation`.

## 5. 상태·종료(REQ-041·042)

- 상태 6개: 준비 → 실행 → (사용자 확인 대기) → 완료 / 실패 / 중지. 활성 실행은 하나.
- 대기 사유: `uncertain`(다시 / 중지), `tests_changed`(인정 후 계속 / 중지), `config_file_changed`(계속 / 중지), `user_edit`(포함해 계속 / 중지), `no_tests`(완료 인정 / 중지). 앞 셋의 계속은 OS 확인 창. `unattended`면 대기 없이 `needs_human` 실패.
- 종료 사유: 완료 `completed`·`user_accepted`·`review_reported` / 실패 `needs_human`·`setup_error`·`rounds_exhausted`·`limit_time`·`limit_turns`·`usage_limit`·`budget`·`provider_error`·`bad_output`·`config_mismatch`·`sandbox_violation`·`service_restart` / 중지 `user_stop`. 시작 거절 `stale_preview`·`busy`.
- 한도: 단계 벽시계 계획 10·구현 20·검토 10·수정 15분, 판정 300 s, Claude 턴 30·60·30·40, 수정 왕복 2(0~2), API 키 모드 단계당 1.00 USD [권장안 U-83]. 사용 강도(K8) 보통·낮음 값은 정해지지 않았다 [미정 S6].

## 6. 중복 방지·복구·중지(REQ-011)

- `run.request_id` UNIQUE(같은 값이면 처음 `run_id`), 활성 행 부분 유일 색인 → `busy`.
- 단계는 `pending`으로 먼저 쓰고 `pending → launching` 조건부 UPDATE가 1행을 바꿀 때만 띄운다. 띄움(stdin 열어 둠) → `pid`·실행 파일·생성 시각 커밋 → stdin 쓰기 → 닫기.
- 서비스 재시작: 기록 PID가 살아 있고 경로·생성 시각이 같을 때만 트리 종료. 단계 `uncertain`, 실행은 대기. 에이전트 단계 자동 재실행 없음.
- 중지·시간 초과·설정 불일치 = 곧바로 `taskkill /PID <pid> /T /F`(SIGINT·SIGTERM 안 씀). 끝낸 세션은 `tainted`. 바뀐 파일은 되돌리지 않고 목록만 보인다. 중지는 동반 앱 버튼만.
- 활성 실행 동안 `powerSaveBlocker.start('prevent-app-suspension')`.
- 세션 단위 = (프로젝트, 에이전트 id·판). Claude는 다음 실행이 세션을 잇는다. Codex, `tainted`, 판 바뀜, "새로 시작", `fresh`, 기록 없음, 14일 넘음이면 새 세션 + 앞 실행 요약. 작업 폴더에서 바로 실행(사본 없음) [권장안 U-29].

## 7. 내보내는 사건

| 사건 | 쓰는 곳 |
|---|---|
| `ai_preview{…, candidate_sha256}` | AI 구성 확인 화면 |
| `ai_run{state, step, wait_reason, end_reason}` | 실행 상태 화면. 시작 → 표시 p95 ≤ 1 s, 준비 알림 ≤ 200 ms |
| `ai_problem{cube, kind: error\|wait\|fail\|none, run_id}` | 큐브 둘레([05](05-표시.md) 3절), 화면 제어 모드면 안 그림 |
| `ai_usage`, `ai_changes` | 사용량, 바뀐 파일 목록 |

- 모의 실행기: 가짜 CLI `node.exe mock-agent.mjs --as claude|codex` + 시나리오 JSON(`CUBE_MOCK_SCENARIO`, 형식은 [미정: 모의 실행기를 만들 때 정한다]), 같은 조정 경로. 평가 PC는 `ai.provider = "mock"` 잠금. 시연 중 AI 실패면 모의로 돌리고 [모의 실행]으로 밝힌다 [권장안 U-93].
