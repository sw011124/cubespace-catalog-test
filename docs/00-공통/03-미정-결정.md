# 미정·결정 목록

이 문서로 답하는 것: 구현을 막거나 바꿀 수 있는 결정이 무엇이고, 언제까지 정해야 하며, 정하기 전에는 어떤 값으로 구현하나.

관련: [01-아키텍처](01-아키텍처.md)

- **잠정** 칸의 값으로 지금 구현한다. 결정이 나면 이 표의 행을 지우고 **고칠 곳**의 문서를 고친다.
- 번호: `C` = 묶기 재설계에서 나온 것, `F` = 펌웨어, `H` = 하드웨어, `S` = 소프트웨어, `U` = 예전 사용자 결정 목록의 확정 전 권장안.

## 8. 권장안으로 구현 중인 것 (바뀌면 고칠 것)

확정 기록은 없지만 이 값으로 구현한다. 문서에 나오는 U 번호는 모두 이 표에 있다.

- "(문서 값)"은 예전 권장안과 달라 구현 문서의 값을 적은 것이다.
- U-34·U-66·U-67은 요구 문장([04-요구사항](04-요구사항.md))에만 남고 지금은 구현하지 않는다.
